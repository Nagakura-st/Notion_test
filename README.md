# Notion_test

GitHub MCP の書き込み・Pull Request作成フローを確認するための、依存関係のない静的Webアプリです。

## 内容

- `index.html`：画面の構造
- `style.css`：最小限のスタイル
- `app.js`：カウンターの増加・リセット処理

## ローカルでの起動

依存関係やビルドは不要です。プロジェクトのルートで次を実行し、表示されたURLをブラウザで開いてください。

```bash
python -m http.server 8000
```

WindowsでPythonランチャーを使う場合：

```bash
py -m http.server 8000
```

ブラウザで `http://localhost:8000` を開き、**増やす** と **リセット** が動くことを確認します。

## テスト観点

- [ ] 初期表示が `0` である
- [ ] 「増やす」を押すと数値が1ずつ増える
- [ ] 「リセット」を押すと数値が `0` に戻る
